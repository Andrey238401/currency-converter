## Описание программы

Currency Converter - это GUI-приложение для конвертации валют. Приложение позволяет переводить суммы из одной валюты в другую с использованием актуальных курсов, а также сохранять и загружать историю конвертаций в формате JSON.

### Возможности:

- Конвертация из одной валюты в другую
- Поддержка 6 основных валют: RUB, USD, EUR, GBP, CNY, JPY
- Отображение текущего курса выбранной пары валют
- Автоматическое округление до 2 знаков после запятой
- Сохранение истории конвертаций в JSON-файл
- Загрузка истории из JSON-файла
- Очистка истории и полей ввода
- Валидация вводимых данных (проверка пустых полей, корректность суммы)
- Обновление курсов при смене валютной пары

## Инструкция по запуску

### Требования:

- Python 3.6 или выше
- Tkinter (входит в состав Python)
- requests (для получения актуальных курсов валют)

### Установка зависимостей:

```bash
pip install requests
Запуск:
Откройте терминал или командную строку

Перейдите в директорию проекта:

bash
cd currency-converter
Запустите приложение:

bash
python currency_converter.py
Примеры использования
Базовая конвертация:
Введите сумму в поле "СУММА" (например, "100")

Выберите исходную валюту из выпадающего списка "ИЗ ВАЛЮТЫ" (например, USD)

Выберите целевую валюту из выпадающего списка "В ВАЛЮТУ" (например, RUB)

Нажмите кнопку "КОНВЕРТИРОВАТЬ"

Результат отобразится в поле "РЕЗУЛЬТАТ"

Курс выбранной пары отобразится в поле "ТЕКУЩИЙ КУРС"

Работа с историей:
Сохранение: Нажмите "СОХРАНИТЬ В JSON" - история сохранится в файл conversion_history.json

Загрузка: Нажмите "ЗАГРУЗИТЬ ИЗ JSON" - история загрузится из файла conversion_history.json

Очистка истории: Нажмите "ОЧИСТИТЬ ИСТОРИЮ"

Очистка полей ввода: Нажмите "ОЧИСТИТЬ ПОЛЯ"

Тестовые данные (примеры для проверки):
Попробуйте выполнить следующие конвертации для тестирования:

Сумма	Из валюты	В валюту	Ожидаемый результат (примерно)

50	EUR	USD	~53-58 $
1000	RUB	USD	~10-12 $
100	CNY	RUB	~1200-1400 ₽
10000	JPY	USD	~65-75 $

После выполнения конвертаций попробуйте:

Сохранить историю в JSON, закрыть приложение, затем загрузить обратно

Очистить историю и убедиться, что список стал пустым

Ввести некорректную сумму (буквы) - проверить валидацию

Оставить поле суммы пустым - проверить обработку ошибок

Валидация данных
Поле "СУММА" должно содержать положительное число (целое или дробное)

При пустом поле суммы будет показано сообщение об ошибке

При вводе букв или спецсимволов будет показано сообщение об ошибке

Все валюты должны быть выбраны (по умолчанию выбраны RUB и USD)

При отсутствии интернет-соединения будет использовано резервное значение курса
